# Vision-RL + TinyMPC proof of concept

This bundle is generated by
`python -m tools.crazysim_mujoco.rl.train_mbpo`. A complete trained bundle
contains `checkpoint.pt`, `policy.onnx`, `bundle.json`, and
`training_metrics.json`. The checkpoint and training metrics are evidence;
only `policy.onnx` is loaded at runtime.

The deployment input is two consecutive normalized 160x160 HM01B0 grayscale
frames in `[previous, current]` order. Its categorical actions map to the
existing, versioned navigation packet through the canonical `hybrid_rl`
runtime adapter without changing firmware:

- TRACK -> `(steering=0, collision=0)`
- LEFT -> `(steering=+1, collision=1)`
- RIGHT -> `(steering=-1, collision=1)`

Camera calibration provenance is recorded in each generated `bundle.json`.
Only numeric values from tinympc-perception commit
`890bbd6923a9459d4d7ab7bee92542e4cb61c64d` are used; no third-party texture
or scene asset is copied into this bundle.
