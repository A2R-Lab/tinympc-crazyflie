# Post-frame-fix curved smoke (Slurm 5993)

This is compact negative diagnostic evidence for the controller that projects
gate bearing into the path frame, displaces every reference knot along its own
normal, and rebuilds the tunnel around the shifted horizon.

One fresh seed (`5402`) was run serially on circle, oval, and smoothed
figure-eight on calibrated host `a2r-tiger`. All three passed the physical gate
and all three contacted the scene before completing. The first accepted gate
observation occurred after physical gate crossing in all three trials, so this
diagnostic did not exercise the corrected servo early enough to guide the gate
approach.

The result rejects the narrow hypothesis that the reference-frame mismatch was
the sole curved-course root cause. It does not replace the preregistered 20-run
held-out matrix from job 5990.
