Figure-8 forced-2-second blocked-gap two-fan configuration: posthoc run 3
============================================================================

Configuration
-------------

- Method: posthoc LIMO, mode 2
- Maneuver: two-pass Figure-8 from traj_fig8_12.h
- Maneuver start: forced 2000 ms after OOT takeoff began
- Start state and measured Z baseline: z=0.12 m, vz=+0.17 m/s
- Upward-blowing fan: perpendicular orientation
- Downward-blowing fan: directly in front of the vehicle
- The gap between the upward fan and the downward fan (resting on a box)
  was blocked by another box.

Outcome
-------

- FAILURE: the user observed multiple contacts with the fan, followed by
  `SUP: Locked, reboot required`.
- The last sample before lock was trajectory t=21.694 s, index 434/482
  (90.0%).
- The firmware later printed TRAJ DONE and landing messages, but those events
  occurred after supervisor lock and are physically invalid.
- This run reached the standard t >= 3 s primary window; the table below ends
  at the last pre-lock sample.
