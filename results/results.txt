CONSOLIDATED HARDWARE RESULTS
=============================

Updated: 2026-07-27
Branch/configuration: LIMO hardware campaign

This file consolidates the five hardware campaigns selected for reporting:

  1. Hover under lateral wind: five matched embedded/posthoc trials
  2. Figure-8 under downward airflow: three matched embedded/posthoc trials,
     with three exploratory nominal reference trials
  3. Figure-8 under upward airflow: two matched embedded/posthoc trials
  4. Figure-8 with a 3 g asymmetric aerodynamic payload, no fan: one matched
     nominal/embedded/posthoc triplet
  5. Figure-8 with the same 3 g payload plus wind: one matched
     nominal/embedded/posthoc triplet

Lower is better for every error, tilt, and computation metric.


METRIC AND WINDOW DEFINITIONS
=============================

Primary scored window
---------------------

  Hover:
    First EXP record at or after OOT activation + 3 s through TRAJ DONE.

  Figure-8:
    First EXP record at or after TRAJ START + 3 s through TRAJ DONE.
    The EXP timestamp resets at TRAJ START in the gated-takeoff firmware.

  Landing is excluded from every scored window.

Boundary-refreshed metrics
--------------------------

Let the first retained sample define the disturbance-analysis boundary.

  XY boundary error:
    ||(p_xy - p_xy,ref) - (p_xy - p_xy,ref)_boundary||

  Z error change:
    (z - z_ref) - (z - z_ref)_boundary

  Tilt-vector change:
    ||[roll, pitch] - [roll, pitch]_boundary||

The boundary RMSE and peak therefore measure error accumulated after the
analysis boundary. They are not the same as absolute trajectory-tracking
error.

Figure-8 trajectory note
------------------------

The firmware repeats traj_fig8_12.h twice. The header itself contains three
physical Figure-8 circuits over about 12.04 s, so each approximately 24.1 s
scored flight contains six physical circuits. The boot field "laps=2" means
two passes through the header, not two physical circuits.

2. FIGURE-8 UNDER DOWNWARD AIRFLOW
=================================

Condition
---------

  Reference altitude: 0.70 m
  Airflow: top to bottom
  Trajectory: traj_fig8_12.h repeated twice, about 24.1 s / six circuits
  Arms: 3 matched embedded/posthoc pairs
  Nominal: 3 later exploratory reference trials under the same analysis rule
  Completion: 3/3 for every arm

------------------------------------------------

Key relative effects:

  embedded.
  Embedded Z-change RMSE is 29.3% lower than nominal and 72.6% lower than
  posthoc.
  Embedded tilt-change RMSE is 22.8% lower than posthoc and 35.0% lower than

---------------------------------

Interpretation
--------------

This is a Pareto result. Nominal/posthoc accumulate less boundary-relative XY
error, while embedded LIMO substantially reduces boundary-relative vertical
and attitude excursions. At this 0.70 m stress altitude embedded authority is
effectively saturated (w = 1.0), so this campaign tests always-active
in-solver placement rather than authority scheduling.

4. 3 G ASYMMETRIC AERODYNAMIC PAYLOAD, NO FAN
==============================================

Condition
---------

  Payload: 3 g of paper attached to the front-right propeller guard
  Wind: no external fan reported
  Reference altitude: 0.70 m
  Trajectory: traj_fig8_12.h repeated twice, about 24.1 s / six circuits
  Arms: one matched nominal/embedded/posthoc triplet
  Completion: 1/1 for every arm

This is not a centered mass-only test. The paper introduces added mass,
off-center center of mass, inertia mismatch, aerodynamic drag/torque, local
rotor/guard inflow interference, and possible flexible flutter. No
payload-specific model or controller compensation was used.

CROSS-CAMPAIGN SUMMARY
======================

  Hover:
    Embedded wins the five-pair boundary-refreshed XY, Z, and tilt
    comparison.

  Aggressive Figure-8:
    Embedded consistently trades boundary-relative XY performance for
    substantially tighter boundary-relative Z regulation and lower attitude
    excursion. This trade is present under downward flow, upward flow, the
    asymmetric payload, and payload-plus-wind.

  Posthoc mechanism:
    Whole-flight infeasibility is high in every campaign where the projection
    is exercised: 70.8% downward, 66.9% upward, 62.7% payload, and 64.1%
    payload plus wind. The corrected infeasible path returns the nominal
    command, so observed posthoc degradation comes from feasible one-step
    interventions, not a broken fallback.

  Real-time feasibility:
    No scored arm recorded a 50 ms deadline overrun. The closest observed
    campaign step was embedded LIMO at 49.496 ms in the downward-flow
    Figure-8 campaign.

  Statistical status:
    Hover has n=5 matched pairs; downward Figure-8 has n=3 matched pairs;
    upward Figure-8 has n=2 matched pairs. The payload and payload-plus-wind
    campaigns each have only one matched triplet and are mechanism/feasibility
    demonstrations until repeated.
